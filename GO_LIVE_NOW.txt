5 MINUTES - MONGODB SETUP
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. Go to: https://www.mongodb.com/cloud/atlas

2. Sign up (Google account fastest)

3. Create free cluster:
   - Click "Create" → "Shared Cluster"
   - Region: Choose closest to you
   - Name: lineoa-saas
   - Click "Create Cluster"

4. Create database user:
   - Go to "Security" → "Database Access"
   - Click "Add New Database User"
   - Username: saasadmin
   - Password: [Set strong password - SAVE THIS!]
   - Click "Add User"

5. Get connection string:
   - Go to "Clusters" → Click "Connect"
   - Choose "Drivers"
   - Copy connection string:
     mongodb+srv://saasadmin:PASSWORD@cluster...net/lineoa

6. Update PASSWORD in connection string with your actual password

SAVE THIS: MongoDB Connection String

10 MINUTES - DEPLOY TO VERCEL
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Option A: Using GitHub (Recommended)

1. Push to GitHub:
   git add .
   git commit -m "Deploy"
   git push origin main

2. Go to: https://vercel.com

3. Sign up or login (GitHub button easiest)

4. Click "New Project"

5. Select your "lineoa-saas" repository

6. Click "Import"

7. Go to "Settings" → "Environment Variables"

8. Add three variables:

   Variable 1:
   Name: MONGODB_URI
   Value: [Paste your MongoDB connection string from above]
   Click "Add"

   Variable 2:
   Name: JWT_SECRET
   Value: [Generate: node -e "console.log(require('crypto').randomBytes(32).toString('hex'))"]
   Click "Add"

   Variable 3:
   Name: NODE_ENV
   Value: production
   Click "Add"

9. Click "Deploy"

10. Wait 2-3 minutes... (Vercel will show progress)

11. You'll get a URL like: https://lineoa-saas-xyz.vercel.app

TROUBLESHOOTING
═══════════════════════════════════════════════════════════════════════════════

Problem: Deployment fails
Solution:
  1. Check Vercel logs (Deployments tab)
  2. Verify MONGODB_URI is correct
  3. Verify JWT_SECRET is set
  4. Try redeploying

Problem: App won't load
Solution:
  1. Check MongoDB Atlas - is cluster running?
  2. Check Vercel logs
  3. Verify environment variables

Problem: Sign-up not working
Solution:
  1. Check browser console (F12)
  2. Check Vercel logs
  3. Verify MongoDB connection
