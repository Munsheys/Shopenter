🏗️ ARCHITECTURE SUMMARY
───────────────────────────────────────────────────────────────────────────

Request Flow - Admin (JWT-Protected):
  Merchant Login → JWT Generated → Stored in Cookie → 
  Admin API Request → JWT Extracted → Query Filtered by merchantId → 
  Response with merchant-specific data only

Request Flow - Storefront (Public):
  Customer visits /merchant/[merchantId] → 
  Extract merchantId from URL → 
  Public API call to /api/storefront/[merchantId]/* → 
  Query filtered by merchantId → 
  Display merchant-specific products & branding

Data Isolation:
  ✅ Every query: { merchantId: ... }
  ✅ JWT carries merchantId
  ✅ Path params provide merchantId
  ✅ No cross-tenant data visible
  ✅ No hardcoded merchant references
