  ┌──────────────────┐
  │ Settings         │  ← Singleton (ONE only)

  │  └─ liffId       │
  │  └─ promptPayId  │
  └──────────────────┘

  │

  ┌────────────────────────────────────────┐
  │ Merchant (NEW)                         │  ← Many documents

  │  ├─ shopName: "My Shop"                │
  │  ├─ liffId: "liff_shop1"               │
  │  └─ promptPayId: "123456_shop1"        │
  │                                        │

  │  ├─ _id: "shop2"                       │

  │  ├─ liffId: "liff_shop2"               │

  ├─ Product.find({ merchantId: "shop2" })       → Only shop2's products

  └─ Customer.find({ merchantId: "shop2" })      → Only shop2's customers

  ├─ /dashboard                                   → Admin (multi-tenant)
  ├─ /merchant/shop1                              → Shop1 storefront
  ├─ /merchant/shop2                              → Shop2 storefront
  └─ /merchant/[id]                               → Dynamic per merchant

DATA ISOLATION: THE SECURITY MODEL
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  ✅ CORRECT (Owner 1 can only see Owner 1's data)
  ─────────────────────────────────────────────

  Owner 1 logs in with JWT:
    { merchantId: "shop1", email: "owner1@shop1.com" }

  Requests products:
    GET /api/merchant/products
    ↓
    Query: Product.find({ merchantId: "shop1" })
    ↓
    Returns: [Product A, Product B] (shop1 only)


  ❌ WRONG (Security Hole - returns all data)
  ───────────────────────────────────────────

  Owner 1 logs in with JWT:
    { merchantId: "shop1", email: "owner1@shop1.com" }

  Requests products:
    GET /api/merchant/products
    ↓
    Query: Product.find({})  ← NO FILTER!
    ↓
    Returns: [All products from ALL shops] ← LEAKED!


MERCHANT LIFECYCLE
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  1. Signup
     POST /api/merchant/auth/signup
     { email, password, shopName }
          ↓
     Create Merchant document
     Generate merchantId

  2. Login
     POST /api/merchant/auth/login
     { email, password }
          ↓
     Generate JWT with merchantId
     Store in localStorage

  3. Access Dashboard
     GET /dashboard
     (uses JWT from localStorage)
          ↓
     Middleware extracts merchantId from JWT
          ↓
     Only show THIS merchant's data

  4. Setup Configuration
     POST /api/merchant/settings
     { liffId, promptPayId, ... }
          ↓
     Update Merchant document
          ↓
     Store is LIVE at: /merchant/[merchantId]
