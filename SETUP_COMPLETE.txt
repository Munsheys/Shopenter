💡 KEY CONCEPTS TO REMEMBER
────────────────────────────────────────────────────────────────────────────

1. MERCHANTID is your namespace
   One field separates unlimited merchants

2. EVERY QUERY filters by merchantId
   ❌ Product.find({})
   ✅ Product.find({ merchantId: req.user.merchantId })

3. JWT carries merchantId
   So merchant knows which data is theirs
   { merchantId: "shop1", email: "owner@shop.com" }

4. PATH-BASED now, SUBDOMAIN-BASED later
   Can change routing without touching database

5. TEST with 2+ MERCHANTS always
   Verify isolation works before moving on
