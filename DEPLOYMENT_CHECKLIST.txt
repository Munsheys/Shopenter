═══════════════════════════════════════════════════════════════════════════════
TROUBLESHOOTING
═══════════════════════════════════════════════════════════════════════════════

Problem: "MongoDB connection error"
Solution:
  1. Verify MONGODB_URI is correct
  2. Check IP whitelist in MongoDB Atlas (Network Access)
  3. Verify username/password are correct
  4. Check that cluster is running

Problem: "JWT validation failed"
Solution:
  1. Make sure JWT_SECRET environment variable is set
  2. Try signing up again
  3. Clear cookies and refresh

Problem: "Site won't load"
Solution:
  1. Check logs in Vercel/Heroku dashboard
  2. Verify all environment variables are set
  3. Try redeploying

Problem: "Products won't save"
Solution:
  1. Check MongoDB connection in logs
  2. Verify database has correct permissions
  3. Check that MONGODB_URI is correct
